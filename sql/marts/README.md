# Витрины

Витрины создаются файлом `sql/ddl/006_mart.sql` после таблиц DWH.

- `mart.v_current_vacancies` - доступные вакансии из последнего успешного снимка.
- `mart.v_market_overview` - объём рынка и покрытие зарплатами.
- `mart.v_top_skills` - навыки с рангом внутри направления.
- `mart.v_salary_by_group_region` - медиана только для вилок с двумя границами.
- `mart.v_weekly_new_vacancies` - новые публикации и изменение к прошлой неделе.
- `mart.v_employers_three_directions` - работодатели сразу в трёх направлениях.

Вакансия, которой нет в свежем поиске, автоматически не получает статус закрытой.
Для этого нужна отдельная проверка карточки и таблица `dwh.fact_vacancy_status_check`.
