# Проверка проекта

Последняя полная проверка выполнена 26 октября 2026 года на PostgreSQL 16.

## Живой запуск

Источник - открытый API «Работа России». Период конфигурации - 90 дней по дате
изменения записи в источнике, направления - Data Analyst, BI Developer и Data
Engineer. Это не означает, что каждая вакансия впервые опубликована в этом окне.

```text
Результатов по запросам источника: 958
Отсеяно по названию:              912
Принято поисковых строк:           46
Уникальных вакансий:               36
Работодателей:                     22
Регионов:                          13
Вакансий с зарплатой:              33
```

Одна вакансия может встретиться в нескольких запросах, поэтому 46 принятых строк
превращаются в 36 уникальных вакансий.

Распределение актуального снимка:

| Направление | Вакансий | С зарплатой |
| --- | ---: | ---: |
| Data Analyst | 27 | 24 |
| BI Developer | 5 | 5 |
| Data Engineer | 4 | 4 |

Данные «Работы России» не считаются полной картиной российского IT-рынка. Этот
прогон нужен для проверки реального ETL-процесса, обработки шумной выдачи и
работы аналитических витрин.

## Автоматические проверки

Все 34 модульных теста прошли успешно. Они проверяют API-клиенты, повторные
попытки после ошибок, конфигурацию, нормализацию зарплат, фильтрацию заголовков,
удаление контактных полей, пересчёт дашборда после фильтров, кэш карточек,
деление поисковых сегментов и наличие нужных SQL-конструкций.

После загрузки DWH были запущены шесть SQL-проверок:

```text
duplicate_vacancy_in_snapshot: 0
invalid_salary_bounds: 0
missing_required_vacancy_fields: 0
orphan_snapshot_vacancy: 0
rejected_rows: 0
segment_over_2000: 0
```

Нулевой результат означает, что проверка не нашла ошибочных строк.

## Как повторить

```bash
export DATABASE_URL='postgresql://job_market:change_me@localhost:5432/job_market'
docker compose up -d postgres
python scripts/run_sql.py ddl
python -m ingestion collect-trudvsem \
  --config config/trudvsem_segments.json \
  --raw-dir data/raw-trudvsem \
  --database-url "$DATABASE_URL"
python scripts/run_sql.py load
python scripts/run_sql.py quality
python -m unittest discover -s tests/unit -v
```

API меняется со временем, поэтому количество вакансий в новом запуске будет
другим. Воспроизводимая техническая проверка без интернета доступна через
`python -m ingestion sample --input data/sample --output build/sample`.
